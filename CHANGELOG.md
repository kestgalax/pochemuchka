# Changelog

Все заметные изменения в проекте документируются здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.2] — 2026-06-18

### Изменено

- **AI-перспектива: мост, приложение+агент, среда исполнения.** В `pochemuchka` и README — три типа посредника между намерением и результатом; берег описан как среда исполнения (`пользователь → среда → инструменты / API / БД / агенты`), с ценностью переноса из А в Б, атомов работы и связки существующих систем.
- **Обязательный артефакт AI-проверки.** После линзы навык выводит текст + таблицу: точка А→Б, посредник, тип артефакта, атомы/связка.
- **`pochemuchka-render` — рендер AI-проверки.** HTML-шаблон поддерживает блок с таблицей и badge для типа артефакта (мост / приложение+агент / среда исполнения).

## [1.1] — 2026-06-18

### Изменено

- **Навык `pochemuchka` — единое меню дальнейших действий.** Шаги 6, 7 и 8 (предложить follow-up, сохранить .md, HTML-визуализация) объединены в один шаг «Предложить дальнейшие действия». Теперь агент в одном сообщении предлагает три варианта:
  - продолжить глубже,
  - сохранить как .md,
  - оформить красиво (.md + HTML).

  Раньше эти опции предлагались последовательно — сначала углубление, потом сохранение, потом HTML. Теперь пользователь видит весь выбор сразу.

- **«Оформить красиво» автоматически сохраняет оба формата.** При выборе этого варианта сохраняется и markdown-файл, и HTML-страница — без дополнительного шага.

## [1.0] — 2026-05-29

### Добавлено

- Навык `pochemuchka` — метод анализа коренных причин через цепочку «Почему?» с линзой «Данные → Контекст, Проблемы → Намерение, Решения → Принципы».
- Навык `pochemuchka-render` — рендеринг результата почемучки в автономную HTML-страницу с тёмной/светлой темой.
- Установщики `setup.sh` (macOS/Linux) и `setup.bat` (Windows).
- Примеры применения в `examples/`.
